
# Student Portfolio & FYP Showcase System

## Project Description
This is a web-based Student Portfolio and Final Year Project Showcase System developed using PHP, MySQL, HTML, CSS, JavaScript and Bootstrap.

The system allows students to view assignments, submit their projects, upload files and view their submissions. Administrators can manage categories, create assignments and view student submissions.

## Technologies Used
- HTML, CSS and Bootstrap
- JavaScript and AJAX
- PHP
- MySQL
- Laragon
- Git and GitHub

## Database Setup
Database Name: assignment_system

1. Start Apache and MySQL in Laragon.
2. Open phpMyAdmin.
3. Create a database named assignment_system.
4. Import the assignment_system.sql file.
5. Check that the database tables are created successfully.

## Project Setup
1. Clone this GitHub repository into C:\laragon\www.
2. Open the project folder in Visual Studio Code.
3. Check the database connection settings in db.php.
4. Open the project in your browser:

http://localhost/Mini_Project_2_Portfolio_Showcase/

5. Register a student account and log in.

## Admin Setup
For local testing, register an account first.

Then use phpMyAdmin to assign the admin role to that account by updating its role in the users table.

Log out and log in again to access the admin dashboard.

## Main Features
- Student registration and login
- Role-based access control
- Student and admin dashboards
- Assignment management
- Portfolio and assignment submission
- File upload validation
